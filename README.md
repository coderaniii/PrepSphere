🚀 PrepSphere

> A full-stack learning platform to track DSA progress with authentication and persistent storage.


 🌐 Live Demo
🔗 [https://snazzy-florentine-d09697.netlify.app](https://snazzy-florentine-d09697.netlify.app/)


 ✨ Features

- 🔐 User Authentication (Login / Signup)
- 🧠 DSA Progress Tracker UI
- 💾 Data stored using MongoDB
- ⚡ Fast and responsive frontend
- 🔄 Backend API deployed on Render

 🛠️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Deployment**
- Netlify (Frontend)
- Render (Backend)

 📦 Backend API

🔗 https://prepsphere-0p2v.onrender.com

⚙️ How it Works

1. User signs up / logs in
2. JWT token is generated
3. User interacts with tracker
4. Data is sent to backend
5. MongoDB stores user progress

 🚧 Current Limitations
